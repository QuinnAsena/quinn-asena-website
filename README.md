# Quinn Asena: Personal Research Website

This is the source for my website [quinnasena.github.io](https://quinnasena.github.io/quinn-asena-website/), built with [Quarto](https://quarto.org/).

## Building locally

1. [Install Quarto](https://quarto.org/docs/get-started/) (v1.4 or later recommended).
2. Clone this repository.
3. Preview the site with live reload:

   ```bash
   quarto preview
   ```

4. Or render the full site to the `_site/` directory:

   ```bash
   quarto render
   ```

## Updating the CV

The CV is a PDF built from the Typst source in the separate `CV-typst` repo, and a copy
lives here at `cv/quinn-asena-cv.pdf` so the download link cannot break independently of
this site. After recompiling the Typst source, copy the new PDF across:

```bash
cp ../CV-typst/cv-a-sidebar.pdf cv/quinn-asena-cv.pdf
```

If the file size changes noticeably, update the size shown on the button in `cv.qmd`.

## Content kept in sync with the CV repo

Two blocks on this site are generated by hand from CSVs in `CV-typst/csvs/` and must be
updated alongside them. Each is marked with an HTML comment naming its source file:

- `my-research.qmd` publication list, from `publications.csv`
- `talks.qmd` chronological talk record, from `positions.csv` (`section == workshops_conferences`)

These are static rather than generated at build time because the deploy workflow installs
Quarto only, with no R, and the CV repo is not available to the runner.

## Deployment

The site is deployed to [GitHub Pages](https://pages.github.com/) via the `gh-pages` branch.

A GitHub Actions workflow (`.github/workflows/publish.yml`) automatically renders and publishes the site on every push to `main`. To publish manually:

```bash
quarto publish gh-pages
```
